IMDb Ratings by Year

Chapter 17 · MongoDB Aggregation Pipelines

One server pipeline → one Streamlit summary

Compute Near the Data

  • MongoDB filters, joins, groups, and computes.
  • The client receives a small summary, not millions of documents.
  • Every client can submit the same pipeline.
  • Streamlit displays the result; it does not repeat the aggregation.

One Question, Two Collections

Mean movie rating by release year, with at least 1,000 votes.

Collection Fields
titles _id, title_type, start_year
ratings _id, average_rating, num_votes

Same IMDb _id links the records. Use 1990–1999.

Read the Pipeline Left to Right

Filter movies → join ratings → unwrap the match

Filter votes → group by year → sort → name the columns

Each stage receives the previous stage’s output.

All seven stages execute inside MongoDB.

Keep the Movies; Attach Ratings

{"$match": {"title_type": "movie",
            "start_year": {"$gte": 1990, "$lte": 1999}}}

{"$lookup": {"from": "ratings", "localField": "_id",
             "foreignField": "_id", "as": "rating"}}

rating is an array, even when there is just one match.

Decide Which Movies Count

{"$unwind": "$rating"}

{"$match": {"rating.num_votes": {"$gte": 1000},
            "rating.average_rating": {"$type": "number"}}}

No rating match? Dropped. Too few votes? Dropped.

One Summary per Year

{"$group": {
    "_id": "$start_year",
    "rated_movies": {"$sum": 1},
    "mean_rating": {"$avg": "$rating.average_rating"},
    "total_votes": {"$sum": "$rating.num_votes"}
}}

Each movie has equal weight in the mean.

Make the Answer Displayable

{"$sort": {"_id": 1}}

{"$project": {"_id": 0, "year": "$_id",
              "rated_movies": 1, "total_votes": 1,
              "mean_rating": {"$round": ["$mean_rating", 2]}}}

Sort explicitly. Rename the year. Round only the result.
