IMDb movie ratings by year

Continue with the Chapter 16 MongoDB server and imported imdb.titles and imdb.ratings. The importer in chapter-14-mongo-indexes/code/import-imdb-mongo.py creates the snake_case fields used here; do not substitute the raw TSV names.

From the repository root, in Bash:

cd chapter-17-mongodb-aggregation/code
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt

Set MONGODB_URI in this terminal using the Chapter 16 connection instructions. Use the existing credentials; do not put them in source code. The default database is imdb; MONGODB_DATABASE is an optional override for a test database.

python aggregation_queries.py --start 1990 --end 1999 --min-votes 1000
python -m streamlit run imdb_aggregation.py --server.address 0.0.0.0

In Codespaces, open forwarded port 8501 and keep its visibility Private. Press Summarize movie ratings. The table and chart are the server result; Pandas only arranges columns for display. No client-side grouping occurs. The pipeline is read-only; neither command imports or replaces data.

A 30-second server limit keeps an expensive demo bounded. If it times out, reduce the year range. The Chapter 16 compound index on (title_type, start_year) can help the first stage if already present; this lesson does not create indexes. The join uses the existing ratings._id index. Full-dataset timing depends on the server, data snapshot, and indexes; a tiny fixture cannot establish that timing.

Verify with an isolated server

With mongod on PATH (or MONGOD=/absolute/path/to/mongod), run:

python -m unittest discover -v

Tests create and stop their own loopback-only MongoDB server in a temporary directory. They never use MONGODB_URI to seed or delete course data. Missing mongod skips live tests explicitly. The fixture is invented, not an IMDb extract.
